В этом пререлизе IS74Wifi получает прямое подключение для работы с VPN, выбор обслуживаемых подключений и новый экран диагностики Wi-Fi.

- **Авторизация при включённом VPN.** Программа теперь должна восстанавливать доступ к Campus Wi-Fi без отключения VPN: запросы авторизации идут через выбранный физический адаптер по сохранённым IP серверов. Адреса сохраняются между запусками; для нового пути могут использоваться известные адреса того же сервера из других подключений. Сценарий с включённым VPN успешно проверен на ноутбуке.
- **Выбор сетей и адаптеров.** В настройках появился список с чекбоксами: Campus Wi-Fi выбран по умолчанию, дополнительно можно отметить USB/Ethernet телефона или указать SSID его Wi-Fi-раздачи. Программа обслуживает выбранные подключения, не перебирая все VPN и виртуальные интерфейсы.
- **«Сигнал Wi-Fi и точки доступа».** Новый информационный экран в главном меню показывает текущее подключение и доступные точки, сигнал, BSSID, диапазон, канал, стандарт Wi-Fi и скорости радиосоединения. Есть прокрутка и ручное обновление. Скорость радиосоединения не равна скорости интернета; экран не переключает точки доступа и не меняет настройки сети.
- **Удобнее первый запуск.** После согласия на статистику и регистрации программа предлагает включить автоматическую авторизацию и выбрать обслуживаемые подключения. Больше не нужно искать эти настройки самостоятельно. Прерванная настройка продолжается при следующем запуске.

Также упорядочена диагностика: подробные сведения о сетевых путях собраны в TXT-отчёте, подписи состояния стали понятнее. Фоновые проверки учитывают значимые изменения выбранных подключений; лишние уведомления Windows не создают повторных HTTP-запросов и не засоряют журнал.

**Ограничения.** Это экспериментальный пререлиз для Windows x64. VPN с блокировкой прямого трафика вне туннеля, включая kill switch, может препятствовать авторизации. На чистой установке без известных IP первоначально нужен работающий DNS. Если срок авторизации неизвестен, обнаружение потери доступа зависит от уведомлений Windows или ручной проверки. Отдельные радиопоказатели зависят от драйвера и доступности данных Windows.

Скачайте из Assets файл `IS74Wifi-v0.1.0-alpha.48-win-x64.exe`. Установка .NET не требуется; рядом доступна контрольная сумма SHA-256.

Локально пройден полный набор проверок клиента и приватного серверного исходника. Релизная сборка дополнительно проверяется и собирается в GitHub Actions. Подробные данные окружающих Wi-Fi-сетей и BSSID не добавляются в анонимную телеметрию.
